# avtoru-reseller-finder

Скилл для Claude: находит на **Авто.ру** частных продавцов с двумя и более машинами (вероятные перекупы) и складывает их в Excel со ссылками на профиль и объявление, без дублей. Рассчитан на ручной запуск и на ежедневный автозапуск по расписанию.

*English: a Claude skill that finds private sellers on Auto.ru who have 2+ cars in their public garage ("likely resellers") and saves them to dated Excel files, deduplicated across all previous runs. No phone numbers are collected and no messages are sent.*

## Что делает

1. **Спрашивает критерии** перед запуском: модели, регион, размер порции, минимум машин в гараже. В автозапуске (человека рядом нет) вопросов не задаёт и берёт сохранённые критерии.
2. **Создаёт папку** `AutoRu_Resellers` на рабочем столе (находит настоящий рабочий стол, в том числе в OneDrive).
3. Обходит выдачу Авто.ру по моделям (только частники), открывает объявление и профиль продавца, считает машины в гараже без пометок «Бывшая» и «Машина мечты».
4. Сохраняет **новый файл на каждый запуск**: `001_resellers_2026-10-16.xlsx`, `002_…` и т. д. Дубли отсекаются по ID профиля среди всех прошлых файлов папки.
5. В таблице: ссылки на профиль и объявление, что в гараже, колонка «Уверенность», выпадающий «Статус контакта» (`не писали`, `написали`, `ответил`, `отказ`, `не отвечает`, `не перекуп`), журнал запусков.

## Чего скилл не делает (намеренно)

- Не собирает телефоны и другие контакты, не нажимает «Показать телефон».
- Не пишет продавцам. Связь идёт вручную через чат площадки по ссылке на объявление.
- Не обходит капчу и ограничения: при капче или 403/429 останавливается и сообщает.
- Не входит в аккаунт.

Гараж в профиле не равен числу объявлений на продаже, поэтому результат это оценка («вероятные перекупы»), а не факт. Перед рассылкой проверьте профиль глазами.

## Установка

Нужны: Claude с браузерным расширением **Claude in Chrome** и постоянным разрешением для `auto.ru`, Python 3 с `openpyxl` (`pip install -r requirements.txt`).

Скилл это папка [`skills/avtoru-reseller-finder`](skills/avtoru-reseller-finder) с одним файлом `SKILL.md`. Он самодостаточен: весь код встроен в приложения внутри файла.

- **Claude Code:** скопируйте папку `skills/avtoru-reseller-finder` в `~/.claude/skills/` (на Windows `%USERPROFILE%\.claude\skills\`).
- **Claude (приложение/веб):** загрузите папку или ZIP с ней в разделе настроек, где добавляются свои скиллы.

Затем скажите Claude: «найди перекупов на Авто.ру».

## Автозапуск

Раз в день, небольшой порцией (3 модели по 8 продавцов, не больше 400 запросов), как запланированная задача в приложении Claude. Один раз вручную: выдать расширению постоянное разрешение для auto.ru и отключить сон компьютера. Подробности и готовый текст задачи в разделе «Автозапуск» в [`SKILL.md`](skills/avtoru-reseller-finder/SKILL.md).

## Структура

| Путь | Что это |
|---|---|
| `skills/avtoru-reseller-finder/SKILL.md` | сам скилл (инструкции + весь код в приложениях A–F) |
| `js/` | сборщик для вкладки браузера (`collector.js`), опрос прогресса, выгрузка порциями |
| `scripts/` | `setup_folder.py` (папка и критерии), `build_xlsx.py` (Excel с номером и датой), `known_ids.py` (ID из прошлых файлов) |
| `tests/smoke_test.py` | проверка нумерации файлов и отсева дублей: `python3 tests/smoke_test.py` |

Файлы в `js/` и `scripts/` это копии приложений из `SKILL.md`, для удобства чтения и тестов. Источник правды: `SKILL.md`.

## Ответственность

Данные профилей на Авто.ру публичны, но это персональные данные частных лиц. Используйте скилл в рамках правил сайта и законодательства вашей страны (в России это 152-ФЗ), не рассылайте спам и не передавайте собранные списки третьим лицам. Вёрстка сайта меняется: если сборщик возвращает 0 карточек, обновите селекторы (раздел «Заметки о сайте» в `SKILL.md`). Проект не связан с Авто.ру.
